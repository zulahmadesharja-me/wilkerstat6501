# WebGIS Wilkerstat Kabupaten Malinau

WebGIS Wilkerstat Kabupaten Malinau merupakan aplikasi peta interaktif untuk menampilkan dan menelusuri wilayah kerja statistik di Kabupaten Malinau.

## Fitur

- Menampilkan batas kecamatan, desa, dan Sub-SLS.
- Menyediakan data periode 2025-2 dan 2026-1.
- Menyediakan pilihan peta dasar.
- Filter berdasarkan kecamatan, desa, dan Sub-SLS.
- Pencarian nama dan kode wilayah, termasuk kode RT.
- Popup informasi atribut wilayah.
- Label wilayah pada peta.
- Fitur lokasi pengguna.
- Tampilan responsif untuk desktop dan perangkat seluler.

## Publikasi GitHub Pages

1. Unggah seluruh file aplikasi ke repository.
2. Buka Settings → Pages.
3. Pilih Deploy from a branch.
4. Pilih branch main.
5. Pilih folder /(root).
6. Klik Save.
